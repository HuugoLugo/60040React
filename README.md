# Proyecto e-commerce - Hugo Lugo

Este proyecto es desarrollado para el curso de react en coderhouse.

Se trata de una tienda de panadería en línea que muestra sus categorías de productos, el detalle de los mismos, un carrito de compra con los productos seleccionados, así como una orden de compra que incluye los datos registrados por el cliente.
Permite agregar productos a un carrito de compra, removerlos, e inclusive vaciarlo por completo, modificandose así la cantidad de productos y el total de la compra.
***

## Tecnologías / Librerías
* **Frontend**: [React](https://es.react.dev/learn) - [React Router Dom](https://www.npmjs.com/package/react-router-dom) - [React Icons](https://react-icons.github.io/react-icons/) - [React Toastify](https://fkhadra.github.io/react-toastify/installation) - [SweetAlert2](https://sweetalert2.github.io/#download)
* **Build**: [Vite](https://vite.dev/guide/)
* **Backend**: [Firebase](https://firebase.google.com/?hl=es-419)
* **Deployment**: [Vercel](https://vercel.com/)

Descripción:

Esta aplicación web fue construida utilizando React como framework principal, utilizando javascript (jsx) como lenguaje de programación. Vite se encargó de compilar y servir la aplicación durante el desarrollo. Para la navegación entre las diferentes páginas se utilizó React Router DOM. Los iconos fueron añadidos con React Icons, mientras que las notificaciones se muestran utilizando React Toastify y SweetAlert2. La lógica del backend y el almacenamiento de datos se gestiona con Firebase. Finalmente, la aplicación se despliega en Vercel para una fácil distribución.
